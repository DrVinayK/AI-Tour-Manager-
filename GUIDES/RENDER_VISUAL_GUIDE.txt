TROUBLESHOOTING FLOWCHART
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: Backend won't deploy
    │
    ├─ Check Render Logs (Logs tab)
    │  ├─ "No module named" → missing in requirements.txt
    │  ├─ "KeyError" → missing environment variable
    │  └─ "Unable to find" → wrong start command
    │
    └─ Fix: Update code/config and git push

Problem: Frontend won't deploy
    │
    ├─ Check Render Logs
    │  ├─ "ModuleNotFoundError" → gunicorn not in requirements.txt
    │  ├─ "Cannot import app" → app.py has issues
    │  └─ "Connection refused" → FASTAPI_BASE_URL wrong
    │
    └─ Fix: Update config and git push

Problem: "Backend failed..." in UI
    │
    ├─ Check FASTAPI_BASE_URL in frontend env vars
    ├─ Verify backend service is running (check Render dashboard)
    ├─ Wait 30-60 seconds (cold start)
    └─ Reload page

Problem: Slow first load
    │
    ├─ Free tier? → Normal (cold starts are slow)
    │  └─ Upgrade to Starter for faster response
    │
    └─ Paid tier? → Might have other issues
